## 동작 보존

기존 Python 77개를 이동 전 백업과 비교했습니다. import 경로, 파일 위치에 따른 프로젝트 루트 계산, 실행 예시의 변경을 제외하면 구문 트리가 동일합니다. 계산식과 분석 조건은 변경하지 않았습니다.

기존 자료 일부를 읽기 전용으로 사용해 표준·고속 IDW의 보정 없음·고정감률 보정 출력을 이동 전후 대조했습니다. 네 비교 모두 데이터프레임이 동일했습니다. 자료·DB의 경로 기준도 프로젝트 루트로 유지했습니다.

이전에 확인한 키 누락 시 요청 차단·오류 로그의 인증값 비노출 검사는 이번 전체 테스트에 포함했습니다. 의존성 파일은 변경하지 않았고 기본·지형 모듈의 import를 확인했습니다.
