# 검증 기록

2026-09-09, Windows와 Python 3.12.14에서 확인했다. 새 관측자료나 연구 실험을 생산하지 않고 기존 코드·자료의 재현과 공개 구성을 검사했다.

## 공개 파일만 사용한 검증

원자료·내부 문서·로컬 경로 설정이 없는 별도 폴더에 공개 파일만 복사해 실행했다.

| 검사 | 결과 |
|---|---|
| Python 문법 | 공개 Python 77개 통과 |
| 모듈 import | 대화형 `check_data.py`와 테스트를 제외한 58개 통과 |
| `unittest discover -p 'test_*.py' -v` | 330개 실행, 실패·오류 없음, `skipped=14` |
| `test_idw_lapse_methods.py` | 5개 검사 통과 |
| `test_lapse_rate.py` | 30개 검사 통과 |
| `test_stage0_invariants.py` | 13개 검사 통과 |
| `test_kma_security.py` | 키 기본값·키 누락·로그 노출 관련 3개 테스트 통과, 위 unittest에 포함 |
| 의존성 | `pip check` 충돌 없음, 기본·지형 의존성 import 확인 |

생략 14건은 외부 SQLite가 필요한 통합 테스트 10개, 로컬 정본이 필요한 2개 클래스의 준비 단계, 정본 CSV가 필요한 개별 테스트 2개다. 자료가 없어 생략된 것이며 통과로 집계하지 않았다. 실제 정본을 사용하는 마지막 2개 개별 테스트는 원래 로컬 자료가 있는 환경에서 별도로 실행해 모두 통과했다.

최종 경로 검토에서 고도·시간대 분석이 메타데이터 설정을 따르도록 보완하고, 외부 경로를 출처 해시에 기록할 때 절대경로를 남기지 않도록 수정했다. 관련 회귀 테스트 2개를 추가해 고도·시간대 테스트 32개를 통과했다.

초기 검사에서 감률 입출력 테스트가 기존 결과 폴더에 의존하는 것을 발견해 전용 임시 폴더를 쓰도록 바꿨다. 정본 CSV가 없는 경우의 생략 조건은 파일 존재 여부에만 적용했으며 기존 수치 검증은 유지했다.

## 변경 범위 확인

IDW·고도 환산·감률·BIAS 핵심 계산 모듈 10개는 정리 전 원본과 바이트 단위로 동일했다. `find_stations.py`와 `load_aws.py`의 함수 본문도 구문 트리로 동일함을 확인했다. 변경은 자료 위치 설정·키 처리·글꼴 위치·테스트 준비 조건과 문서에 한정했다.

공개 파일의 알려진 기존 키, 토큰·개인키 패턴, 연락처, 사용자·장비별 절대경로와 Markdown 상대 링크를 검사했다. 숫자 CSV의 소수 부분이 전화번호 패턴에 걸린 1건은 숫자 컬럼의 오탐임을 확인했다. 공개 제외 설정과 실제 추적 대상도 대조했다.

## 실행하지 않은 항목

- KMA API 실제 호출과 2024년 전체 재다운로드
- 전체망 LOO 원자료 재생산과 `validate_stage0.py`·`validate_fast_idw.py`의 연간 전량 재계산
- bootstrap 후속 분석의 전국 생산 실행과 내부 보고서 전체 재생성
- 지도 원본 재취득, 원격 DEM 다운로드와 전국 지형 재분류
- 모든 PowerShell 그림의 재생성, macOS/Linux 실행

위 항목의 미실행을 연구 결과의 재실험 통과로 표현하지 않는다. PowerShell 파일은 구문을 검사했다.

## 소개 범위 변경 (2026-09-09)

여러 분석의 목적과 구성 중심으로 문서를 바꾸고, 개별 실험의 그래프·수치·결과 파일은 최신 공개 구성에서 제외했다. 이 수정은 코드와 의존성을 변경하지 않아 계산 테스트를 다시 실행하지 않았다. 문서 상대 링크와 공개 파일 목록을 확인했다.
