# 보간과 평가 방법

## IDW와 고도보정

평가 시각에 운영 중인 관측소의 유효 기온을 사용하며 평가 대상 자신을 제외한다. Haversine 거리 30km 안에서 가까운 이웃을 최대 10개 사용하고, 유효 이웃이 3개 미만이면 해당 시각을 보간하지 않는다. 가중치는 `w_i=1/d_i²`이다. 거리 0인 이웃은 기존 구현의 직접값 분기를 사용한다.

`fixed_lapse`는 각 이웃의 기온을 기준 고도 0m로 옮긴 뒤 같은 거리 가중치로 보간하고, 목표 관측소 고도로 되돌린다.

```text
T_ref,i = T_i + γ × (0 − z_i)
T_ref   = Σ(w_i × T_ref,i) / Σw_i
T_pred  = T_ref + γ × z_target
γ       = −0.0065°C/m
```

`none`은 기온을 보정하지 않는다. 고도 결측은 해당 환산 단계에서 입력값을 그대로 유지하는 기존 fallback을 사용한다. 이웃 기온·거리·고도·가중치·기여도는 `idw_interpolate_with_trace`로 확인할 수 있다.

`monthly_lapse`는 해당 월의 감률을 고정감률 계산에 전달하고, `band_lapse`는 고도구간별 감률을 이동 경로에 따라 적분한다. `lapse_rate.py`의 전국 회귀·게이트·감률 제한·월별 중앙값 테이블을 사용한다. 초기 8개 지점 비교의 결과는 [실험 결과](results.md)에 별도로 적었다.

## 자료 처리와 날짜

- 메타데이터 CSV는 CP949로 읽고 저장 CSV는 UTF-8 BOM(`utf-8-sig`)을 사용한다.
- `지점`, `시작일`, `종료일`, `위도`, `경도`, `노장해발고도(m)` 컬럼을 원문 그대로 사용한다.
- `filter_station_meta_for_period`는 자료 로드 전에 기간과 겹치는 후보를 줄인다. `filter_valid_station_meta`는 평가 날짜의 실제 운영 이력을 선택한다. 두 역할은 다르다.
- AWS 다운로드에서 기상값 `≤−50`은 결측으로 바꾼다. 로더는 기온을 숫자로 변환하고 동일 시각 중복은 마지막 행을 유지한다. 결측 기온 이웃은 보간에서 제외한다.
- 사용자 입력 종료일은 포함한다. 함수 내부와 조회 API의 필터는 `[start, end)`이므로 직접 함수를 호출할 때는 끝 시각을 제외하는 규칙에 맞춘다.

## 표본과 집계

| 단계 | 표본 | 의미 |
|---|---:|---|
| 전체망 후보 | 549개 | 메타데이터·관측소 폴더·2024년 데이터가 겹치는 지점 |
| 전국 성능 평가 | 529개 | 보간 가능한 유효 관측을 가진 지점, 후보 중 20개 제외 |
| 시간대·고도 주 분석 | 513개 | 연간 180일·9개월 이상, 고도 결측 없음, 연중 고도구간 변경 없음 등의 코호트 조건 |

전국 성능은 모든 유효 관측의 오차 합계를 표본 수로 나눈 pooled 지표이다. 각 방법의 표본 수는 4,475,234개다. 513개 주 분석은 방법별 4,454,204개이며 `station×hour` 단위로 지표를 먼저 계산한다. 고도집단의 중앙값은 이후 관측소마다 같은 비중을 주어 계산한다.

```text
error = predicted − observed
MAE   = mean(abs(error))
RMSE  = sqrt(mean(error²))
BIAS  = mean(error)
```

주간은 09–17시, 야간은 21–05시로 각각 9시간이다. 06시는 전이시각으로 구분한다. station별 주야 지표는 해당 시간대의 오차 합계와 표본 수를 합친 뒤 계산한다. 전·후 집단 중앙값의 차이는 관측소별 짝 차이의 중앙값과 같지 않다.

연속 고도 분석은 각 시각에 513개 관측소를 사용해 지표–해발고도의 단순 회귀기울기(°C/100m), R², Spearman 상관을 구한다. 고도구간을 물리적 임계값으로 해석하지 않는다.

## 후속 진단과 해석 범위

BIAS 분석은 보정 전후의 방향과 크기, 이웃과의 가중 고도차, 관측소 지형 등과의 연관성을 살펴본다. 유의성 분석은 월층화 원형 이동 블록 bootstrap과 다중검정 보정을 사용한다. 주 설정은 7일 블록, 2,000회 재표집, 실질 차이 0.10°C, FDR 5%이며 설정별 민감도도 기존 분석에 포함돼 있다.

오차에서 역산한 `γ_eff`는 오차를 설명하는 진단값이다. 직접 관측한 대기 감률이 아니며, 고도차가 작을 때 불안정해진다. 주변 지상 관측소의 기온–고도 관계가 양수인 `inversion_like`도 실제 연직 기온 프로파일의 역전을 측정한 값이 아니다. 연관성·수학적 항등식·물리 가설을 구분해 해석한다.

`fast_idw.py`는 거리·이웃 기하를 미리 계산하고 반복적인 데이터프레임 처리를 줄인 평가 구현이다. 속도는 환경·자료 범위에 따라 달라지므로 고정 배수의 성능 보장은 하지 않는다. 기존 구현과의 수치 비교는 `validate_fast_idw.py`에서 수행한다.
