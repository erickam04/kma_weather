**KMA AWS 관측자료를 활용한 기상 데이터 분석**

KMA AWS 관측자료를 수집·정리하고, 기온의 공간 보간과 다양한 조건에서 나타나는 오차를 살펴본 연구 코드입니다. 자료 준비부터 보간 방법 비교, 시간·고도·지형에 따른 분석, 결과 조회와 시각화까지 여러 분석에 사용한 코드를 모았습니다.

## 주요 작업

- **자료 수집과 전처리:** 시간별 관측자료를 관측소·월별로 저장하고, 결측값과 관측소 운영 이력을 반영해 분석 자료를 준비했습니다.
- **공간 보간과 고도보정:** IDW 보간을 구현하고, 고정감률·월별 감률·고도구간별 감률을 적용하는 방법을 비교했습니다.
- **관측소별·전체망 평가:** 단일 지점과 여러 관측소를 대상으로 평가하고, 반복 계산을 위한 병렬 처리와 SQLite 집계·조회 기능을 구성했습니다.
- **오차 특성 분석:** MAE·RMSE·BIAS를 이용해 시간대·계절·고도별 차이와 이웃 관측소의 배치·고도차·지형 특성을 살펴봤습니다. 
- **탐색과 시각화:** 기온 시계열, 이웃 관측소와 가중치, 지도와 대시보드 자료를 만드는 코드를 작성했습니다.

각 분석은 목적에 따라 입력 자료와 설정이 다릅니다. 분석별 역할은 [구성 안내](docs/methods.md), 필요한 자료와 경로 설정은 [데이터 안내](docs/data.md)에 정리했습니다.

## 데이터와 활용 범위

주로 2024년 KMA AWS 시간별 기온(`TA`)과 관측소 위치·고도·운영 이력을 사용했습니다. 지형 관련 분석에는 별도의 지도·고도 자료가 필요합니다. 원자료와 개별 실험의 결과 파일·그래프는 포함하지 않습니다.

eLoran 시간적 ASF 보정에 사용할 기상 입력자료를 준비하는 맥락에서 진행했습니다. 이 저장소는 기상자료 처리와 보간·분석 코드에 해당하며, ASF 딥러닝 모델 학습은 포함하지 않습니다.

## 실행

Python 3.12 환경에서 프로젝트 루트를 기준으로 실행합니다.

```bash
python -m venv .venv
# Windows PowerShell: .\.venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
```

자료를 준비한 뒤 `python run_test.py`로 단일 관측소 평가를 시작할 수 있습니다. 다운로드에는 `KMA_API_KEY`가 필요합니다. 분석별 실행 순서와 선택 의존성은 [실행 안내](docs/running.md)를 참고하세요.

## 주요 구성

```text
├── kma.py / find_stations.py / load_aws.py    # 수집·관측소 정보·자료 준비
├── idw.py / fast_idw.py / elevation_correction.py / lapse_rate.py
├── pipeline_config.py / project_paths.py    # 분석 설정·자료 경로
├── run_*.py / stage*.py / new_*.py           # 실행·전체망 평가·조회
├── analyze_*.py / bias_*.py                  # 오차·통계 분석
├── visualize_*.py / plot_*.py / plot_*.ps1    # 시각화 코드
├── test_*.py / validate_*.py                 # 검증 코드
├── docs/                                   # 구성·데이터·실행 안내
└── requirements*.txt
```

분석마다 대상 기간·관측소·자료 충족 조건이 다르므로 실행 전에 해당 스크립트의 설정을 확인해야 합니다. 일부 후속 분석은 별도로 생성한 중간 자료를 요구하며, 관측자료에서 찾은 연관성을 물리적 인과관계로 단정하지 않습니다.
